Course Evaluation Report Methodology

The Course Evaluation Report contains data on the statistical questions and the 13 official questions, and covers all professors and courses which were evaluated by at least six students.

The report provides for each questionnaire item of a given course:

  • where applicable, the "average score"* obtained on a particular item
  • the number of students responding to a particular response option 
  • the percentage of respondents choosing that particular option
  • the number of students answering that the question was not applicable.
* The "average score" is obtained in the following manner: Each response option is assigned a weight varying by 1, from 5 for the most favourable option to 1 for the least favourable option, as shown in the following example.


Example
If the respective responses are weighted as indicated, the average score is found as follows:

Total points = 34x5 + 8x4 + 2x3 + 1x2 + 1x1 = 211

The total 211 is divided by the number of respondents to the question (46) to yield the average score 4.59.
