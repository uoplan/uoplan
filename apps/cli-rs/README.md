# uoplan

CLI for University of Ottawa students to search courses, manage their shopping cart, and enrol — including a sniper mode that fires enrollment at a precise time.

## Install

**macOS / Linux**

```sh
curl -fsSL https://uoplan.ca/install.sh | sh
```

**Windows**

```powershell
irm https://uoplan.ca/install.ps1 | iex
```

**From crates.io**

```sh
cargo install uoplan
```

## Usage

```
uoplan login              # Authenticate via Chrome (saves session to keychain)
uoplan logout             # Clear stored credentials
uoplan term               # Select a term interactively
uoplan term ls            # List available terms
uoplan search <course>    # Search for a course and add to cart (e.g. CSI2101)
uoplan cart               # Manage shopping cart interactively
uoplan cart add <N>       # Add a course by class number
uoplan enrol              # Enrol in cart courses
uoplan run <payload>      # Execute a schedule payload from uoplan.ca
uoplan fetch <url>        # Debug: fetch a URL with your session cookies
```

The `run` command accepts a base64url-encoded protobuf payload generated by the [uoplan web app](https://uoplan.ca). It adds all selected courses to your cart and optionally:

- **Enrols immediately**
- **Snipes** — waits until a specified time, then retries every 500ms for up to 2 minutes
